# pirataria-crime-ou-problema-de-servico
Trabalho acadêmico sobre pirataria digital, direitos autorais e disponibilidade de serviços legais.
Este trabalho caracteriza-se como uma pesquisa de natureza teórica, com abordagem qualitativa, desenvolvida por meio de revisão bibliográfica de artigos científicos sobre pirataria digital, disponibilidade de conteúdo, percepção de preços e direitos autorais.
